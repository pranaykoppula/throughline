# Programming languages

Last reviewed: 2026-11-19

A family index. The languages and runtimes programs are written in, and the choices built into them: how they do several things at once, what they let a machine check, and what their history left behind.

## In reading order

In the order the spine first needs them, with pages that lean on each other kept together.

1. [Event loops and threads](event-loops-and-threads.md): the ways a program does several things at once, and the bugs each way invites. First needed on [page 2](../02-one-machine-many-programs.md).
2. [Type systems](type-systems.md): writing down what kind of thing each value is, so a machine can check what people would otherwise have to remember. First needed on [page 3](../03-programs-too-big-for-one-head.md).
3. [JavaScript](javascript.md): a language designed in a hurry for small scripts, which became the most widely deployed programming language in the world, quirks included. First needed on [page 6](../06-anyone-can-publish.md).
